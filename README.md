## 两款都是 1 核 1GB，差的不只是硬盘

硬盘是最容易被注意到、也最影响使用体验的一项。HDD 的随机读写比 SSD 弱一个量级，WordPress 后台、MySQL 查询、Docker 拉镜像解压这类操作会先撞到这堵墙。静态页面、编译脚本、跑个探针，HDD 完全撑得住。

其余三项差异同样要算进去：

- **带宽**：LITE 是 300Mbps，L 是 1Gbps。跑代理、做大文件分发、需要扛瞬时并发的场景，300Mbps 会先成为瓶颈。
- **流量**：LITE 每月 500GB，L 是 1TB。个人博客和轻量 API 一般用不到 500GB，视频、图床、下载站会很快用完。
- **系统**：官方明确写了 LITE **仅支持 Linux**。L 没有标注这条限制，但 Windows 授权是否提供，下单前最好问一句客服，别默认能装。

LITE 也有两个不那么显眼的优点：官方说明它支持额外购买流量包，配置最高可升级到 2 核 CPU、2GB 内存。也就是说它并非只能停在 1 核 1G，用量涨上来可以原地扩容，不用迁移。如果你打算先用最低价试水，这个升级路径比一次性买高配更稳。

## 常见问题

**续费会涨价吗？**
官方活动条款（2025 年终活动、2026 双十一活动）都写了续费同价。常规价购买的套餐按标价续费。促销结束后的续费口径，最终以订单页显示的金额为准。

**能装 Windows 吗？**
LITE 明确仅支持 Linux。L 是否提供 Windows 模板，资料未说明，需要向客服确认。

**流量超了怎么办？**
LITE 官方说明支持额外购买流量包。L 的超额处理方式（限速还是停机）资料里没有写明，购买前问清楚。

**1Gbps 是共享还是独享？**
官方页面没有说明端口性质，本文不猜。有计划跑满带宽的业务，直接问客服要端口说明。

**怎么判断自己这边线路好不好？**
用上面三个测试 IP 做 ping 和 traceroute，重点看回程走的是 CN2GIA、10099 还是 CMIN2，比看别人的延迟表可靠。
